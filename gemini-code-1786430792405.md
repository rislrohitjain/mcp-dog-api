   Build, test, and deploy a Python FastMCP server for the Dog API at https://dogapi.dog/api/v2/breeds end-to-end, from local development setup to Git version control and live production deployment on Vercel.

Project Directory and File Requirements

Create a project directory named mcp-dog-api containing the following files:

requirements.txt: Specify dependencies for fastapi, uvicorn, httpx, and mcp.

api/index.py: Initialize a FastMCP instance named Dog API Server. Define an asynchronous tool named get_dog_breeds that uses httpx to fetch data from https://dogapi.dog/api/v2/breeds and return the response text. Create a FastAPI app instance, add a root GET route returning operational status, and mount the MCP SSE application at the /mcp endpoint.

vercel.json: Configure Vercel builds to process api/index.py using the @vercel/python builder and route all incoming requests to api/index.py.

.agents/mcp_config.json: Define a local MCP server entry named dog-api-local pointing to local ip addrss http://172.18.177.164:8000/mcp/sse.

.gitignore: Exclude virtual environment folders, pycache directories, and environment variables.

Step-by-Step Execution Sequence

Local Setup and Testing: Create a Python virtual environment, activate it, and install all listed dependencies. Run the application locally using Uvicorn bound to host 0.0.0.0 on port 8000 with reload enabled. Test the local SSE endpoint at http://172.18.177.164:8000/mcp/sse to verify active connection handling.

Git Tracking and Remote Repository Push: Initialize Git in the project root, add all project files, and make an initial commit. Set the default branch to main, link your GitHub remote repository URL, and push the initial commit.

Vercel Production Deployment: Deploy the application using the Vercel CLI with the production flag. Retrieve your live application deployment base URL.

Final Configuration and Integration: Update .agents/mcp_config.json to replace the local server with a live server entry named dog-api-live pointing to your production URL ending with /mcp/sse. Print a final summary report confirming local verification, Git repository synchronization, and the final production SSE endpoint link ready to paste directly into Gemini Connected Apps.
